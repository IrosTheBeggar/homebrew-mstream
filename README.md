# homebrew-mstream

Homebrew tap for [mStream](https://github.com/IrosTheBeggar/mStream) tools.

```bash
brew install irosthebeggar/mstream/mstream-player
```

installs [mstream-player](https://github.com/IrosTheBeggar/mstream-terminal-player) —
the terminal player and headless server-audio engine — from the prebuilt
release binaries, verified against each release's published sha256 manifest.
Works on macOS (Intel and Apple Silicon) and Homebrew on Linux; the Linux
build needs ALSA at runtime (`sudo apt install libasound2`).

The formula is regenerated by `scripts/bump.sh` from each release's
`manifest.json` — the player repo's release workflow pushes the bump here
automatically, so this tap follows releases on its own.
